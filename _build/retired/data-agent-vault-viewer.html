      Frequently asked questions

      Which sources feed the vault viewer?
      Broker research portals such as BluMatrix, expert network transcripts, SharePoint and other drives, and email attachments. Each source keeps syncing, and the viewer shows when it last did.
      How does Pascal decide which company a file is about?
      It counts tickers, name variants and product lines mapped to each company, then marks the companies a file is about and the ones it only mentions. "Why this is tagged" lists every signal.
      Will analysts see files they are not licensed for?
      No. Lists, counts, sections and Ask Pascal answers all follow each user's permissions. The footer shows how many files were held back and the reason.
      Can I ask questions about the files in a list?
      Yes. Ask Pascal sits under the table and answers from the files in the current list, with citations to the page or timestamp.
      How do agents get the same view?
      Through Pascal's MCP server. list_documents takes the same filters as the viewer and get_document returns the section about a company, under the calling user's permissions.
      Can we add our own document types and columns?
      Yes. Types come from your taxonomy in the classifier, and the columns for each type come from the fields you define for extraction.
