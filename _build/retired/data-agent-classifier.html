Frequently asked questions

What does the classifier do?
It gives every synced file a document type from your taxonomy, with a confidence score and a runner-up. The type decides which fields Pascal extracts and which workflow the file goes to.
Can we use our own document types?
Yes. Rename, split or add types, and give each one its own fields and access rules. A new type needs a small set of labelled examples to start.
What happens to files below the confidence threshold?
They wait in the review queue, and in the vault viewer under Unclassified, until someone assigns a type. Each firm sets its own threshold.
How does one correction change future results?
The file becomes a labelled example for that type. Pascal re-scores similar files straight away and records who made the call and when.
Which file formats can it classify?
PDFs, including scanned ones, Word files, slides, spreadsheets, emails and their attachments.
Who can see the review queue?
Each reviewer sees only the files their permissions allow. A side letter restricted to legal, for example, only reaches the legal team's queue.
