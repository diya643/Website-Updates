Frequently asked questions

Which fields can Pascal extract?
Any field you can point to in a document. Pascal ships schemas for broker reports, expert calls, research notes, credit agreements, NDAs and DDQs, and your team can add fields or new types.
Does it work on scanned PDFs?
Yes. Scanned pages are read with OCR and layout detection. Cells read with low confidence are flagged in the editor for a person to check.
What happens when an analyst corrects a value?
The corrected value replaces the extracted one everywhere it is used. Pascal keeps the original, the editor, the time and the page region alongside it.
Can we define our own schemas?
Yes. Add, rename or remove fields for any document type, set each field's type, and mark which fields need a person to verify them.
How do extracted tables reach Excel or our agents?
Export any table to Excel from the editor. Agents read fields and tables over MCP with get_document, including the page and position of every value.
How do we check a value is right?
Click any cell or field to open the page with the source region highlighted. Totals that do not tie are flagged automatically.
