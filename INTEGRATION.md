# Shipping website v2 to pascalailabs.com

The live site is a Next.js app on Vercel, deployed from GitHub. Website v2 is plain static HTML (best for SEO/GEO:
every word is in the HTML, nothing is rendered client-side). It drops into the Next.js repo's `public/` folder and is
served at clean URLs through rewrites.

Preview of exactly what ships: https://pascal-product-preview.vercel.app (the preview sends `X-Robots-Tag: noindex`;
production must not, and `vercel.json` in this repo does not).

## 2. Copy into the Next.js repo
Copy the **contents** of `website-v2/public/` into the repo's `public/` folder (keep the folder structure).

## 3. Routing
Merge `next.config.snippet.js` into the repo's `next.config.js` / `.mjs`:
- `rewrites().beforeFiles` maps every clean URL to its `index.html`. `beforeFiles` runs before app routes, so these
  pages **replace** the React routes at the same URLs (`/`, `/security`, `/solutions/*`, `/pascal-academy/*`).
  Once verified, delete the old React routes for those paths.
- `redirects()` holds the 301s for retired URLs. The main ones:
  - `/product` → `/platform`
  - `/solutions/asset-management` → `/solutions/asset-wealth-management`
  - `/solutions/private-markets` → `/solutions/private-equity-credit`
  - `/solutions/investment-banking` → `/solutions/banking`
  - `/research` → `/news/founders-notes`
  - and others.

`vercel.json` holds the same redirects and the long cache headers for `/assets/*`, in case you'd rather manage them in
Vercel. You only need one of the two. Asset URLs carry a `?v=<hash>`, so the one-year cache is safe.

## Editing pages later
Edit `_build/pages/*.html` (never `public/` directly), rebuild with `python3 _build/build.py`, copy `public/` again.
The build must end with `0 blocking issue(s)`. Academy pages are generated by `_build/academy/render.py --promote`;
don't hand-edit `academy-*.html`. OG image generation needs the Funnel Display / Funnel Sans font files. On another machine, point `FONTS` in
`_build/build.py` at a local folder that has them.
