Frequently asked questions

What is a Pascal autonomous agent?
An agent you give a whole task to. It runs the task end to end: it plans the work, searches your IC memos, email, Teams, expert calls and broker research alongside public sources, checks what it finds, and delivers a finished, cited document.
Can I see what the agent did?
Yes. Every run shows each search and review step, and you can open any step or stop the run.
Does the agent respect our access controls?
Yes. Agents only search the sources the user running them is cleared to see.
Is the output cited?
Yes. Every figure in the finished document links to its source.
