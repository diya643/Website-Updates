Frequently asked questions

What is the Pascal MCP?
An MCP server that exposes your firm's context graph, documents and Pascal workflows as tools. MCP, the Model Context Protocol, is the open standard AI assistants use to call outside tools and data.
Which LLMs and assistants can connect?
Claude, ChatGPT, Microsoft Copilot, Gemini, Cursor and any agent framework that speaks MCP. Your own apps can use the REST API. Your firm decides which clients are switched on.
How are permissions enforced over MCP?
Each MCP call runs as the signed-in user. Pascal checks access per user and per source before returning anything, and every call is written to the audit log.
Can Pascal call other MCP servers we license?
Yes. Add servers such as filings, Capital IQ or other data vendors with your own credentials. Pascal routes each question to the servers it needs and cites every source in the combined answer.
Which workflows can we run over MCP or the API?
Any workflow in your Pascal workspace, from the workflow library or built by your team. Each one is callable as a slash command in an assistant or as a REST endpoint.
Can the Pascal MCP run inside our VPC?
Yes. Pascal deploys in your VPC on AWS, Azure or GCP, or on premise, and can sit behind open-weight models such as DeepSeek, Mistral or Llama hosted in your own environment.
